# מחברת הכתבה

אפליקציית תרגול הכתבה לכיתה ד׳, בעברית ובאנגלית.

- **עברית:** מילים חדשות בכל פעם, בשלוש רמות קושי ובין 20 ל-50 מילים.
- **אנגלית:** מספרים 1–20 וצבעים, ועובד גם בלי אינטרנט.
- **סנכרון:** קוד אישי מעביר את ההתקדמות בין מכשירים.

## התקנה בטלפון
- **אייפון:** פותחים את הלינק ב-Safari, ואז שיתוף ← "הוסף למסך הבית".
- **אנדרואיד:** פותחים ב-Chrome, ואז תפריט ⋮ ← "התקנת אפליקציה".
